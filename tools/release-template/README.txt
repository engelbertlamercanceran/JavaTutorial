HACKO - how to run
==================

Windows
  Double-click  start-windows.bat
  A black window opens and your browser goes to the game.
  Keep the black window open while playing. Close it to stop.

Mac / Linux
  Open a terminal in this folder and run:  sh start-mac-linux.sh

If it says Node.js is needed
  Install Node.js from https://nodejs.org (choose the "LTS" button),
  then run the start file again.

Notes
  - An internet connection is required to start the game.
  - Your progress is saved in the browser on this computer.
