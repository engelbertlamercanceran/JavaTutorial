# HACKO — test build

A time-limited test copy of the HACKO game. You will need the **access
password**, which the developer gives you separately (it is not on this page).

## How to run it (Windows)

1. Click the green **Code** button above, then **Download ZIP**
   (or use the direct **Download ZIP** link the developer sent you).
2. **Unzip** the file (right-click → *Extract All…*). Keep all the files
   together in one folder.
3. Double-click **`start-windows.bat`**.
   - If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**.
     This is normal for a downloaded launcher and is safe.
   - The first time, it may take a minute to set up (it needs internet once).
4. Your browser opens the game at **http://localhost:8777/**.
   Type the **access password** and play.

Keep the black window open while you play. Closing it stops the game.

## Running it again later

**Before starting it again, close the black window that is already running**
(click it and press **Ctrl + C**, or just close the window). Then double-click
`start-windows.bat` again. Running two at once causes an error.

## Notes

- Internet is needed the first time (to set up) and to start it each time.
- Your progress is saved in the browser on this computer.
- This is a test copy and stops working after the test period ends.
